# 魔搭精修

用户要求“魔搭精修”时，直接使用当前对话实际可用的 `modelscope_retouch` MCP 工具。

1. 使用用户提供图片的绝对本地路径。已授权精修的图片无需重复询问。默认保留主体造型、材质颜色、构图与背景，清理划痕污渍并优化反光；明确要求优先。
2. 分配唯一 run_id，调用 `retouch_submit`，填写 `run_id`、`image_path`、`instruction`。插件仅将本地图片编码上传；模型推理在魔搭云端执行。
3. 使用同一 run_id 调用 `retouch_status`，等待真实 succeeded 状态后调用 `retouch_result`。不要快速密集轮询。
4. 展示 MCP 返回的真实 ImageContent，并简短说明 run_id 与服务回执中的模型/任务 ID；如工具提供本地图片路径，可用绝对路径 Markdown 展示。

不得生成或伪造回执、图片、完成状态。提交失败或超时时先查询同一 run_id，避免重复推理；不要换 run_id 自动重提。不能把本地协议测试、独立 app-server 或验收脚本代调宣称为当前对话原生调用成功。

若当前对话没有精修工具，明确报告插件未加载，不运行替代推理脚本。不索取魔搭 Token，不读取本地凭据。消费者仅需 Node.js 20+ 与可用网络；上游凭据由部署者保存在云端。
