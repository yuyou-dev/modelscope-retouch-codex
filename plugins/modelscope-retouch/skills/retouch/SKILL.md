# 魔搭白底精修

本技能的正式执行方式是当前 Codex 对话执行插件自带 HTTPS 客户端。无需原生 MCP 工具出现在对话工具列表；不要启动另一个 Codex app-server 或编写替代推理脚本。

## 定位与前提

从本 SKILL.md 所在目录解析 `../../client.mjs`，得到当前安装插件的客户端绝对路径。必须使用当前实际安装位置，不硬编码用户名、版本缓存路径或开发仓库路径。需要 Node.js 20+、本地执行能力和可访问魔搭的网络。

使用用户提供并授权处理的 PNG/JPEG/WebP 图片绝对路径，单张最多 5 MiB。附件若不能作为本地文件读取，请用户提供本地文件路径。不要悄悄换图。输出目录选择当前工作区的可写目录，例如 `artifacts/modelscope-retouch`。

## 固定提示词

客户端内固定原项目以下五行，后端另外添加触发词 `精修图片中的饰品`。不得增补、改写、翻译或从图片内容推断额外要求；不得加入“保留背景”。不要修改客户端或云端来绕过固定提示词。

```text
白底精修图，展现珠宝的真实光泽与精致细节。
精修参考图片，保留主体的设计、结构、材质和细节，不增加或改变产品部件。
将背景替换为纯白色，保持自然接触阴影。
优化光影与清晰度，展现金属光泽和宝石质感，避免过度锐化。
去除价格标签、无关文字、灰尘和污点。
```

云端模型 `Qwen/Qwen-Image-2.1-Turbo`，LoRA `yuyou80/refine_jewel_qwen2.1`。本版本只提供固定白底精修；用户提出不同风格时说明能力范围，不擅自改配置。

## 提交、恢复与结果

1. 为新任务分配唯一 run_id，只含英文字母、数字、下划线和连字符，1–80 字符。记录 run_id 和输出目录。
2. 在当前对话执行客户端，按宿主环境正确引用路径：

   ```sh
   node "<客户端绝对路径>" submit "<run_id>" "<输出目录绝对路径>" "<图片绝对路径>"
   ```

   命令没有提示词参数，不要额外传入任何提示词。客户端自动握手、上传原图、轮询、取回图片并校验输出 SHA-256。
3. 如进程仍运行，继续读取该进程输出，不重复提交。若超时、断线或会话中断，用同一个 run_id 恢复：

   ```sh
   node "<客户端绝对路径>" resume "<run_id>" "<输出目录绝对路径>"
   ```

   未查清任务状态前不要更换 ID 重提；云端失败时报告真实错误。
4. 成功以客户端返回的 `saved_image` 绝对路径和回执为准。输出目录的 `.request.json` 记录固定 instruction 与 backend_prefix，可用于核对提示词。查看真实图片，再以绝对路径 Markdown 图片在对话中展示，并提供真实回执文件链接；简要注明模型和 run_id。禁止仅凭 accepted、ping 或工具发现就宣称完成。

如宿主限制网络或本地文件读取，遵守宿主权限流程。不要索取魔搭 Token，不读取环境凭据或凭据存储，不替换云端入口。消费者免魔搭登录，部署者凭据留在云端。

不得伪造回执、图像或状态。将本路线准确描述为“当前对话执行插件 HTTPS 客户端”，不可宣称已通过原生 MCP 工具发现验收。新电脑的安装结果仅按实际验证报告。
